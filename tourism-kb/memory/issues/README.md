# issues/ — lỗi phát hiện khi chạy product

Mỗi issue một subfolder `NNN-slug/`; mọi file liên quan (repro, findings, ghi chú fix)
nằm trong đó. `README.md` mô tả: triệu chứng · cách tái hiện · trạng thái · trỏ tới
bản sửa. Frontmatter `type: issue`, `status: open|done`. Xem `../README.md`.

Khi đóng: lật `status: done` và viết `../history/<ngày>/<vấn-đề>.md`.
