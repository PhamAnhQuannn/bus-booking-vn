# plans/ — kế hoạch cần thực hiện

Mỗi kế hoạch một subfolder `NNN-slug/`; mọi file của kế hoạch đó nằm trong đó.
`README.md` của subfolder là bản kế hoạch (Context · Scope · Steps · Verification),
mở đầu bằng frontmatter (`type: plan`, `status: open|done`). Xem `../README.md`.

Khi làm xong: lật `status: done` và viết một mục `../history/<ngày>/<vấn-đề>.md`.
