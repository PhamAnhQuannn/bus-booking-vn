MỘT file riêng (`<vấn-đề-slug>.md`) — file A cho vấn đề A, file B cho vấn đề B.
Frontmatter `type: history`, `date`. Chỉ ghi thêm; không sửa lại ngày đã qua.

chỉ mục `../lessons/_index.md`). 35 post-mortem cũ (2026-07-27 → 08-01) đã được tách theo

của chúng nằm ở `../../CLAUDE.md` mục "Distilled Rules".
