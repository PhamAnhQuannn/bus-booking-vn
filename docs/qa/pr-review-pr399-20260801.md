Two omissions matter more than the raw count:

already the documented recovery route. It is just incomplete.

**Fix:** add the missing scripts to the reproduce table (or a short "helper modules — not run
directly" list for the four shared modules), and add one setup line naming `.env.tourism.local`
and the three keys it holds.
