- B1 is provably inert without B2 (PR body: "a linked-and-fully-paid-but-stuck event cannot exist" without the orphan row existing at all).

- Shipping any subset would leave the sweeper either still-broken or newly-exploitable — the PR body's "either alone is inert" framing holds up against the diff, not just as a narrative.

The 7 MoMo test fixes are pure mechanical fallout of the `updateMany` call added to the shared `processWebhook.ts` transaction path (confirmed above) — required for this PR to keep the suite green, not a separate change bundled in.
