# Hotelbeds Content API — nguồn hạng/giá khách sạn

status: **todo (cần đối tác)** · nguồn: `documentation/business/tour-discovery/data-sources.md`

Bối cảnh: đăng ký nhà nước (csdl) 403 → mất tín hiệu hạng sao + giá khách sạn cho thành phố mới
(xem [data-access-cuc-du-lich.md](data-access-cuc-du-lich.md)). Hotelbeds Content API là lựa chọn
Phase-1 trong tài liệu discovery.

- Tầng **đối tác có hợp đồng** (không phí theo bản ghi, nhưng phải mở quan hệ đối tác).
- Điều khoản **yêu cầu lưu + refresh hàng tuần** (khác Google — được lưu).
- Cho hạng/giá/nội dung khách sạn có thể lưu hợp pháp.

Việc cần: [ ] đánh giá điều khoản + chi phí. [ ] mở liên hệ đối tác. [ ] so với Agoda Partner API.
Chỉ làm khi scale khách sạn thật cần (theo cheapest-first, không làm sớm).
